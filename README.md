## ⚙️ Features & Modules

*   **Club Dashboard:** Real-time (or counter-based) view of total site traffic, available math lessons, active online gaming sessions, and pending recommendations.
*   **Lessons Portal:** A structured syllabus hub containing math content and practice materials.
*   **Training Ground:** An interactive subsection featuring tools like the **Matrix Problem Generator** to practice linear algebra and math mechanics.
*   **Math Fight:** A gaming space designed for competitive mathematical matches.
*   **Idea Submission Form:** A community feedback route for submitting feature suggestions directly to the platform.

---

## 🛠️ Technology Stack

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+).
*   **Hosting:** Deployed via [GitHub Pages](https://pages.github.com/) using the apex user deployment format under **[Gha15.github.io](https://github.com/Gha15/Gha15.github.io)**.
*   **Domain Mapping:** Configured with a custom apex domain mapping to point directly to `matixthemathclub.com`.

## 💻 Local Setup & Development

To clone, test, or run this website locally on your computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Gha15/Gha15.github.io/
   ```
2. **Navigate into the folder:**
   ```bash
   cd Gha15.github.io
   ```
3. **Run a local static server:**
   * Using Python (Built-in):
     ```bash
     python -m http.server 8000
     ```
   * Using Node.js:
     ```bash
     npx live-server
     ```
4. **View in your browser:** Open `http://localhost:8000` or the port provided by your server software.
