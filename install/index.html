📦 How to install it

🪟 Windows

  1. Download matix-win.zip
  2. Right-click it → Extract All. You can’t run the installer from inside the zip
  3. Open matix-installer.exe
  4. If a blue warning appears, see getting past the warnings
  5. Matix shows up in your Start menu 🎉

🍎 Mac

  1. Download matix-mac.zip and double-click to unzip it
  2. Open the .dmg inside
  3. Drag Matix into your Applications folder
  4. The first launch needs a small trick — see getting past the warnings
  5. After that, open it like any other app

🤖 Android

  1. Download matix-android.zip and unzip it to get matix.apk
  2. Tap the APK
  3. Your phone will ask permission to install from outside the Play Store — allow it
  4. Done!

No unzip app on your phone? Files by Google opens zips, or download it on a computer and send it over.

🛡️ Getting past the security warnings

Windows, Mac and Android all warn about Matix, and that’s expected. It doesn’t mean anything is wrong with it.

It happens because Matix isn’t “code signed” — a certificate that costs hundreds of dollars a year. Matix is a school math club app, not a company. Every small app hits this.

🌐 First — your browser may block the download

Chrome and Edge sometimes say “not commonly downloaded”, or look like the download just failed.

  1. Open your Downloads list (Ctrl+J)
  2. Find Matix and click the ⋯ or arrow beside it
  3. Choose Keep or Keep anyway

🪟 Windows

When the blue “Windows protected your PC” box appears:

  1. Click More info — small text, easy to miss
  2. Click Run anyway

No “Run anyway” button? Windows blocked the file itself:

  1. Right-click matix-installer.exe → Properties
  2. At the bottom, tick Unblock
  3. Click OK and open it again

No Unblock tickbox? Open PowerShell in the folder and run Unblock-File .\matix-installer.exe

🍎 Mac

Mac says “Matix can’t be opened because Apple cannot check it for malicious software” — or, on newer versions, “Matix is damaged and can’t be opened”. Nothing is damaged. That is macOS refusing an app it can’t trace to a paid developer account.

Step 1 — move it to Applications first. Drag Matix out of the disk image into your Applications folder and eject the disk image. Running it from the mounted .dmg fails no matter what else you do.

Step 2 — the Settings route:

  1. Open Matix from Applications, then dismiss the warning
  2. Go to System Settings → Privacy & Security
  3. Scroll down to Security — there should be a line saying Matix was blocked
  4. Click Open Anyway, then confirm with Touch ID or your password

Step 3 — if there is no “Open Anyway” button. On macOS 15 Sequoia and later this is common, and Control-click → Open no longer works either. Apple removed both shortcuts. This always works:

  1. Open Terminal (Spotlight with ⌘+Space, type Terminal, press Return)
  2. Copy this line, paste it in, and press Return:
    xattr -dr com.apple.quarantine /Applications/Matix.app
  3. Open Matix normally

If it answers Operation not permitted, run the same line with sudo in front and enter your Mac password. The password stays invisible as you type — that is normal, just press Return.

🧪

On a macOS beta? Betas tighten Gatekeeper further and the Open Anyway button often never appears at all. Skip straight to the Terminal line in Step 3 — it clears the quarantine flag the download added, which is the actual thing blocking Matix.

You only do this once. After the first successful launch, Matix opens like any other app.

🤖 Android

  1. When you tap the APK, your phone says this source isn’t allowed → tap Settings, turn on Allow from this source, go back and tap the APK again
  2. If Play Protect warns about an unknown app → tap Install anyway (it may be hidden behind More details)

🔄 How to update

New versions get posted on the releases page.

  • 🪟 Windows — just run the new installer. It updates your existing Matix in place, no uninstalling needed.
  • 🍎 Mac — open the new .dmg and drag Matix into Applications again. Choose Replace when asked.
  • 🤖 Android — you do need to uninstall Matix first, then install the new APK. Android refuses to install over the old one.
💾

You won’t lose anything. Your games, ideas, bug reports, lessons, points and profile all live on your Matix account, not on your device. Sign back in and everything is exactly where you left it.
